# Hiking App

A **Kivy-based mobile application** for hill bagging in the UK. The app
allows users to track climbs across different mountain classifications,
either by manually recording a climb or by using the phone's GPS to log
a summit automatically.

## Features

-   Interactive map showing mountain locations
-   GPS-based summit logging
-   Manual climb recording
-   Distance and bearing to nearby mountains
-   Climb history
-   Tracking across different UK mountain classifications

## Technologies

-   **Python**
-   **Kivy**
-   **SQLite3**
-   **Plyer**

## Project Status

This is an **active personal project**. The core application is working,
with additional features and improvements still being developed.

## Installation

Clone the repository:

``` bash
git clone <repository-url>
cd <repository-folder>
```

Install the required Python packages:

``` bash
pip install -r requirements.txt
```

Run the application:

``` bash
python main.py
```

*The application uses mobile-device functionality such as GPS, so some
features require a compatible device and appropriate permissions.*
